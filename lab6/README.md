# Лабораторна робота 6
## Опис 
Проект моделює систему обробки службових нарядів замовлень. Реалізовано базовий абстрактний клас WorkOrder, який узагальнює спільні характеристики нарядів. 
Створено три конкретні підкласи:
AssemblyOrder замовлення на збірку
MaintenanceOrde замовлення на обслуговування 
QualityCheckOrde замовлення на контроль якості
